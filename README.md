# 🎓 InCollege - Sistema de Gestión Industrial de Indumentaria

Plataforma profesional desarrollada en **ASP.NET Core 8.0 (MVC)** para la administración de empresas de indumentaria de egresados. El sistema digitaliza el flujo completo desde el presupuesto hasta la cobranza de cuotas.

## 🚀 Características Clave

* **💰 Gestión Financiera:** Matriz de control de pagos en tiempo real con cálculo automático de deuda y estados (Al día / Parcial / Mora).
* **📄 Contratos Inteligentes:** Generación de códigos únicos por contrato y alumno para trazabilidad bancaria.
* **👥 Padrón Masivo:** Carga y gestión de listados de alumnos con asignación de talles.
* **🧩 Patrones de Diseño:** Arquitectura robusta utilizando **Composite** (para Kits de productos) y **Factory Method**.
* **📊 Dashboard Gerencial:** KPIs de ventas, producción y alertas de contratos caídos.

## 🛠️ Tecnologías

* **Backend:** C# .NET 8.0, Entity Framework Core (Code First).
* **Base de Datos:** SQL Server.
* **Frontend:** Razor Views, Bootstrap 5 (Diseño Dark Mode Industrial).
* **Arquitectura:** N-Capas (Web, Dominio, Datos).
